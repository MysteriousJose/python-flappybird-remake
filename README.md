# Flappybird - Python Pong Remake

A fan-made recreation of the classic flappybird arcade game built entirely in Python using the CMU Graphics library.

This project was created as an educational programming project to practice game development concepts such as animation, collision detection, keyboard input, and game logic.

## Features

* Single player flappybird game
* 3 levels; Easy, Medium, Hard
* Speed Scaling Based off of score

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/MysteriousJose/python-flappybird-remake.git
cd python-flappybird-remake
```

## Requirements

* Python 3.x
* CMU Graphics

  
### 2. Install Requirements

Install Python from:
https://www.python.org/downloads/

Then install project dependencies:


```bash
pip install -r requirements.txt
```

### 3. Run the game

```bash
python main.py
```


The required Python packages are listed in:

```
requirements.txt
```

### Player 1
